# talon -- the LithTech "Talon" tools, rebuilt from source

The editing tools for *No One Lives Forever* and *Aliens versus Predator 2*,
the last ones Monolith released for its 2.x engine generation ("Talon"),
reconstructed as C++ that compiles to the binaries that shipped, function
by function, with the compilers that built them:

- **DEdit** and **ModelEdit** of the *AvP2 Editing Tools* Update 1/2
  (December 2001, the "Talon" builds that import `.lta`), which edit both
  games' worlds (`.ed`, version 1249) and models (`.abc` v12);
- the **world processors** that compile those worlds: AvP2 v1.0's (writes
  AvP2's world version 70) and NOLF Tools 001's (NOLF's 66) -- each game's
  engine takes only its own (`../../FORMATS.md`);
- the **3ds Max and Maya plug-ins** of Update 2 (March 2002).

The same project's other half, `../jupiter/`, builds the next engine
generation's tools (NOLF2, Contract J.A.C.K., Tron 2.0) from Build 69's
source. The reconstruction method and tools are nolfsrc's, nolf2src's and
cjacksrc's (`tools/`, `tools/guides/`); `docs/PLAN.md` says what is done
in what order, `../../INVENTORY.md` where every shipped binary comes from, and
`RETAIL_BUGS.md` lists the bugs found in the retail tools, for fixing when
they are re-implemented.

## Building

```sh
git submodule update --init      # tools/, toolchains/, rez/
make reference                   # the shipped binaries -> out/reference/ (build/reference.sh)
make                             # build everything reconstructed so far
make progress                    # score it; fails if an identical function stops matching
make progress-update             # record the score here and in progress/
make test                        # behaviour: shipped tools vs ours on the same inputs (tests/)
```

Needs docker, the `cjacksrc-build` image, and the compilers
`toolchains/msvc-6.00-8966` and `msvc-6.00-9044` (`toolchains/README.md`).
`make reference` needs the *AvP2: Primal Hunt* (Europe) disc image
(redump.org 35760) and the NOLF Game of the Year disc 2:
`rez/fetch-isos.sh avp2-ph-eu nolf-eu-goty` fetches both from archive.org,
and `build/reference.sh` says where else it looks and checks them. CI
(`../../.github/workflows/talon.yml`) runs all of the above.

## Where the source comes from

Nothing of these tools' source survives, but most of what they are made of
does, in later or neighbouring trees, and each target starts from the
nearest one and is brought back to what shipped:

- `src/Libs`, `src/Engine/sdk/inc`: the LithTech Jupiter SDK (build 51,
  March 2002): Monolith's shared libraries with their own VC6 project
  files, and the engine SDK headers;
- `src/Engine/tools`: taken file by file (`build/takeb69.py`) from Build
  69's tools source (`../jupiter/src`, 2006), the plug-ins' direct
  descendant -- the Update 2 plug-ins are, apart from a few bytes, the
  Jupiter SDK build 51's;
- for DEdit, ModelEdit and the processors (no source of any version): the
  AvP2 source release's LT2 SDK and libraries (`~/src/avp2`), nolfsrc's
  reconstruction of the LT2 engine, and Build 69's DEdit, ModelEdit and
  PreProcessor, their descendants, as a map of their structure.

Every file is committed as it was taken, and each change to it is a commit
of its own.
